# GCP Data Engineering - Introduction

This repository provides a foundational introduction to Data Engineering using Google Cloud Platform (GCP). It is designed for beginners who want to understand core concepts, tools, and workflows involved in building scalable data pipelines on GCP.

## 🚀 Objectives

- Understand the basics of Data Engineering
- Learn key GCP services used in data workflows
- Build simple data pipelines
- Explore real-world use cases

## 🛠️ Technologies & Tools

- Google Cloud Platform (GCP)
  - BigQuery
  - Cloud Storage
  - Dataflow
  - Pub/Sub
  - Dataproc
- Python (for data processing)
- SQL (for data analysis)
